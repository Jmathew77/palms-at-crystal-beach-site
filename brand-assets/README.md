# The Palms Brand Assets

Download-ready logo and header files for The Palms at Crystal Beach RV Resort.

- `the-palms-logo-square.png` - square logo for Facebook profile images, forms, and general avatar use.
- `the-palms-logo-horizontal.png` - wide logo for documents, forms, email headers, and website use.
- `the-palms-logo.svg` - scalable vector logo for design tools and print/vendor use.
- `the-palms-facebook-cover.png` - Facebook cover image sized at 1640 x 624.
- `the-palms-forms-header.png` - wide form/header banner sized at 1600 x 400.

Brand colors:

- Palm green: `#0B3D35`
- Deep teal: `#073F3A`
- Sand: `#F5EFE3`
- Warm cream: `#FAF7EF`
- Sun gold: `#F2B84B`
- Beach turquoise: `#1FA6A8`
